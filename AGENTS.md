# go-ibkr

Unofficial Go client for the Interactive Brokers Web API (Client Portal API v1), generated from the OpenAPI document Interactive Brokers publishes. If you only want to use the client from an agent, read [.agents/skills/go-ibkr/SKILL.md](.agents/skills/go-ibkr/SKILL.md) instead; this file is about changing the code.

## Architecture

One generated package, `ibkr`, at the module root, driven by `gen.go`:

`scripts/fetch-spec.sh openapi.json` downloads `https://api.ibkr.com/gw/api/v3/api-docs` to `api/openapi.json` → `scripts/patch-spec.sh` writes `api/openapi.patched.json` with the defects that stop oapi-codegen fixed → oapi-codegen with `config.yaml` → `client.gen.go`.

## Stack

- Go 1.26.9.
- oapi-codegen, pinned as a `tool` dependency in `go.mod`.
- Runtime: `github.com/oapi-codegen/runtime`.

## Layout

- `gen.go`, `config.yaml`, `client.gen.go`: the package.
- `client_test.go`, `example_test.go`: tests, including the README example.
- `scripts/`: spec download, the spec patch, lint and security scan scripts.
- `api/`: the downloaded and patched spec, gitignored.
- `vendor/`: committed, regenerated by `make dep`.

## Dev workflow

Everything runs in the `Dockerfile.dev` image. You need Docker and Make.

```bash
make dep       # go mod tidy + go mod vendor
make generate  # download the spec, patch it and regenerate
make lint      # shellcheck, shfmt, go fix, golangci-lint
make test      # go test -race
make sec       # gitleaks, govulncheck, semgrep
```

## Project-specific landmines

- The published spec declares path parameters its path templates do not contain, leaves placeholders undeclared and repeats operation IDs. oapi-codegen refuses all of these, so generation without `patch-spec.sh` fails.
- The duplicate operation ID suffixes (`GetTradingSchedule2`) depend on the order operations appear in the spec. An upstream reorder can swap which method gets the suffix.
- Spec paths carry their full prefix (`/v1/api/...`, `/gw/api/v1/...`), so the base URL is scheme and host only. Adding a path to the base URL doubles the prefix.
- `make generate` always downloads the current spec, so it can change the client even when nothing here changed. Review the generated diff before committing it.
